# Geração e Cruzamento de Cenários — MD 2036

Ferramenta pedagógica para transformar eventos prospectivos em combinações possíveis de futuro.

## O que a ferramenta faz

- Busca eventos e probabilidades-base do módulo Delphi;
- gera automaticamente todas as combinações Ocorre / Não ocorre;
- calcula a probabilidade estimada de cada cenário;
- mostra ranking dos cenários mais prováveis;
- permite simulação manual com Ocorre / Não ocorre / Indiferente;
- exibe cenários salvos pré-preenchidos para storytelling;
- permite exportar JSON e CSV.
